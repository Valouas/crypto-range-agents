# Journal de livraison V3

Base : archive V2 fournie par le propriétaire, préservée. Cette livraison ajoute une voie d'observation authentique autonome et prépare les améliorations économiques et de logique du plan de passage à Codex.

Étapes locales versionnées : base V2 ; schémas/permissions/objectif économique ; moteur partagé et authenticité ; corrections de réintégration, de grille et d'assemblage ; documentation et contrôles bornés ; extraction indépendante et contrôle d'intégrité.

Les rapports artificiels de démonstration et anciens résultats ne sont pas inclus comme exemples de résultats V3. Les tests V2 sont conservés sous archive documentaire, hors découverte pytest. Les nouvelles suites distinguent les contrôles autorisés des validations événementielles différées.

À chaque nouvelle livraison, régénérer le manifeste d'empreintes. Un code modifié après validation n'est plus exactement l'artefact contrôlé. Les données réelles restent dans un dossier séparé et ne doivent jamais être mélangées aux fixtures.
